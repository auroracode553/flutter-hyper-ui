## 默认布局

提供 label 时使用 plain 标签行，不附带卡片背景、描边或阴影；标签与开关均可操作。基础示例直接展示控件，不额外包裹 HyperCard。

## 交互动画

轨道保留 52×32，边框 1、内部 padding 4；保留原来的滑块约束盒，圆形可见直径仍为 22。位置、轨道颜色与滑块颜色由同一个临界阻尼弹簧进度驱动，mass / stiffness / damping 为 1 / 1000 / 63.2455532，逻辑方向随 RTL 调整。快速反向切换从当前进度继续；系统启用“减少动态效果”时直接定位。

滑块固定为玻璃，按住开关或标签行时底色淡出；背景与轨道独立录制，模糊 8→0，折射边缘/位移 5/10，并显示色散、高光和内阴影。轨道取样缩放水平 2/3→3/4、垂直 0→3/4，松开或取消恢复。效果限定在原滑块范围，不放大、拉伸或调整轨道、外边距、标签行与点击区域。禁用及无 onChanged 的控件保留原有静态配色，不响应按压。

状态仍由 value 控制，点击释放后通过 onChanged 请求切换，每次有效点击只回调一次；材质动画不派发业务回调，也不新增拖动切换。Flutter 使用内部实色表面与引擎模糊，不执行 Compose 的自定义像素折射。
