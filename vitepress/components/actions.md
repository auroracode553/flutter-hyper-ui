## 选择动作层级

| 变体 | 使用场景 |
| --- | --- |
| `filled` | 页面当前最重要的提交或继续操作 |
| `tonal` | 重要但不主导页面的动作 |
| `outline` | 与主操作并列的次级操作 |
| `ghost` | 工具栏或紧凑区域中的低强调动作 |
| `danger` | 删除、退出等不可逆或高风险动作 |

同一视觉区域通常只保留一个 `filled` 动作。加载状态会阻止重复提交，但异步任务的生命周期仍由业务层管理。
