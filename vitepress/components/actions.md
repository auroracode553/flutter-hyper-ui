## 显示类型与配色

| 参数 | 可选值与作用 |
| --- | --- |
| type | 省略为默认白色描边；filled 填充、icon 圆形图标 |
| colorStyle | primary、success、info、warning、danger 语义配色；省略为白色中性样式 |
| color | 自定义基色，优先于 colorStyle；根据 type 应用于背景、文字和轮廓 |
